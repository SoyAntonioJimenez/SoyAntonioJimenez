## Projects

**[Cathode TV](https://github.com/SoyAntonioJimenez/Cathode-TV)**
A CRT television for the desktop, written in Rust with egui and FFmpeg. VHS library with
covers, 916 internet radio stations, YouTube streaming without downloading, subtitles
generated with Whisper and live capture of any window on Windows.

**[Croma](https://github.com/SoyAntonioJimenez/Croma)**
Recolours folders in Windows without replacing the system icons: it re-tints the real
icon from `shell32.dll` and keeps the shading. C# and WPF, with the palette generator,
the registry side, per-folder `desktop.ini` and the icon cache workaround.

**[Recyclo](https://github.com/SoyAntonioJimenez/Recyclo)**
Recycle bin in the notification area, with the empty and full states drawn in code
instead of shipped as images. C# and WinForms, single executable.

**[Secure Password Generator](https://github.com/SoyAntonioJimenez/Secure-Password-Generator)**
and **[Shutdownator 3000](https://github.com/SoyAntonioJimenez/Shutdownator3000-Apagator3000)**
are two Python/tkinter utilities from 2023.

## Abynth Audio

I also publish audio software under [Abynth Audio](https://github.com/AbynthAudio).
[CarveSpace](https://github.com/AbynthAudio/CarveSpace) is a 32-band spectral sidechain
carver: a native VST3 plugin in C++ that analyses a sidechain signal and ducks the
matching frequencies in the track it is inserted on, so two sounds can share the same
range without fighting. Zero latency, GPLv3, for Linux, Windows and macOS.
